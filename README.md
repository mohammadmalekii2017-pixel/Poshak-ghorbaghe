# POSHAK — فروشگاه سبک Next.js

## اجرا
```bash
npm install
npm run dev
```
سپس `http://localhost:3000` را باز کنید.

این نسخه یک فرانت‌اند سبک و بدون افزونه اضافی است. تصاویر نمونه از Unsplash استفاده می‌کنند. برای فروش واقعی باید سبد خرید، دیتابیس، پنل مدیریت و درگاه پرداخت به‌صورت جداگانه اضافه شوند.
